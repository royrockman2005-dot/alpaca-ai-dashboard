# Alpaca AI Dashboard

Public **demo-only** Streamlit dashboard. Does not connect to Alpaca, Gemini, private GitHub Actions artifacts, or any account. No API keys or secrets are needed. No orders are submitted.

## Deploy

At https://share.streamlit.io create an app from GitHub using:
- Repository: `royrockman2005-dot/alpaca-ai-dashboard`
- Branch: `main`
- Main file path: `dashboard.py`
- Python: 3.12

Keep Secrets empty. This repository is public: do not commit credentials or private reports. Before showing real trading/account data, add authentication and a private server-side data integration.
